Functions with parameters

Pass values into a function so one block of code can work with different data.

KEY IDEA

A parameter is a placeholder in a recipe. area(w, h) is the recipe; area(3, 4) is cooking it with real ingredients, called arguments.

Try it

⌨ ON THE COMPUTER 
def area(w, h):
    return w * h

width = int(input())
height = int(input())
print("Area:", area(width, height))
