## The big idea

There are two ways to join things in `print()`.

**A comma is glue with gaps.** Python puts a space between each part for you, and it is happy to mix text and numbers.

**A plus is superglue.** It sticks text together with **no** space, and it only joins text to text.

```python
name = "Sam"
age = 12
print("Hi", name, "you are", age)          # Hi Sam you are 12
print("Hi " + name + " you are " + str(age))  # Hi Sam you are 12
```

Both lines print the same thing. With `+` you type the spaces inside the speech marks yourself,
and you must turn numbers into text with `str()`.

<Note title="Joining is called concatenation">
`"Hi" + "Sam"` gives `HiSam`. No space is added. Put the space inside the speech marks: `"Hi " + "Sam"`.
</Note>
