## The big idea

Almost every program follows the same three steps, like a recipe:

1. **Input**: read the numbers. Use `int(input())` so they are numbers, not text.
2. **Process**: do the sum and keep the answer in a new variable.
3. **Output**: print the answer.

```python
age = int(input())          # 1. input
future_age = age + 5        # 2. process
print("In five years:", future_age)   # 3. output
```

Read `int(input())` from the **inside out**: `input()` collects the text, `int()` turns it into a number, and `=` puts it in the box.

<InputFlow typed="12" />

<Note title="Maths order">
Python does `*` and `/` before `+` and `-`. So `2 * 8 + 3 * 5` is `16 + 15`, which is `31`.
</Note>
