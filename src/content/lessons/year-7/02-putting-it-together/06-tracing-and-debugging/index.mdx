## The big idea

A **trace table** lets you be the computer. You go one line at a time and write down what is in every box.

The trickiest line is one like this:

```python
score = score + 5
```

Read it from the **right**: take what is in `score`, add 5, then put the answer back in the `score` box. The old value is thrown away.

## Swap two values

To swap two boxes you need a spare box called `temp`. Without it, the first value is overwritten and lost.
Assume the user types red, then blue.

<TraceTable
