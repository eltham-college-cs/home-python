## The big idea

`input()` is like a waiter taking your order. The program stops and waits until
you answer. Whatever you type comes back as **text**, even if it looks like a number.

`int()` is like a currency exchange: it swaps the text `"15"` for the number `15`,
so you can do sums with it.

<InputFlow typed="15" />

<Note title="Always store the answer in a box">
`name = input()` keeps the answer in the variable `name`. Without the `name =` part, the answer is thrown away.
</Note>
