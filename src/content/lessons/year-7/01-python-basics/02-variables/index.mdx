## The big idea

A **variable** is like a labelled box in the computer's memory.

- The **label** is the variable's name.
- The box holds **one value** at a time: text or a number.
- Put a new value in and the old one is thrown away.

<MemoryBoxes boxes={[
  { name: "name", value: "\"Mr Gordon\"" },
  { name: "age", value: "12" },
  { name: "colour", value: "\"blue\"" }
]} />

```python
name = "Mr Gordon"    # a string
age = 12              # an integer
colour = "blue"       # a string
```

The name goes on the **left** of `=`, and the value on the **right**. Read `=` as "is set to".

<Note title="Naming rules">
Use letters, numbers and `_`. No spaces (`my_age`, not `my age`). Don't start with a number. Capitals matter: `Age` and `age` are different boxes.
</Note>
