## The big idea

`print()` is the computer's **speech bubble**. Whatever you put inside the brackets appears on the screen.

Python has different kinds of data. Today we meet two:

- A **string** is a piece of text. It always wears speech marks: `"Hello"`.
- An **integer** is a whole number, like `7`, `42` or `-3`. No speech marks.

<MemoryBoxes boxes={[
  { name: "a string", value: "\"Hello\"" },
  { name: "an integer", value: "12" },
  { name: "a string!", value: "\"12\"" }
]} caption='Speech marks make it text. 12 is a number, but "12" is text.' />

You can do maths with integers: `+` add, `-` subtract, `*` multiply, `/` divide.
Python does `*` and `/` before `+` and `-`, just like in maths.
