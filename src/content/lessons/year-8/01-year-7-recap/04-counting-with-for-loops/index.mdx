## The big idea

A **for loop** is like a coach saying "run 3 laps". The coach counts the laps for you, and the loop variable holds the lap number each time round.

`range(a, b)` counts from `a` up to, **but not including**, `b`. A third number is the **hop**: how far to jump each time. A negative hop counts down.

| Code | Gives |
|---|---|
| `range(2, 6)` | 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |
| `range(10, 0, -2)` | 10, 8, 6, 4, 2 |
| `range(5, 5)` | nothing at all |
