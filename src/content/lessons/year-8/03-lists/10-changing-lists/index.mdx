## The big idea

A list is not fixed once you have made it.

```python
scores = [12, 19, 7]
scores.append(25)    # add 25 to the end: [12, 19, 7, 25]
scores[0] = 20       # overwrite item 0:   [20, 19, 7, 25]
print(scores[-1])    # -1 is always the last item: 25
print(len(scores))   # how many items: 4
```

Read `scores.append(25)` aloud as "scores, append 25": the list is being told to do something.

<Note title="Never write list = list.append(...)">
`append` changes the list itself and hands back nothing (`None`). `shopping = shopping.append("milk")` replaces your list with `None`.
</Note>
