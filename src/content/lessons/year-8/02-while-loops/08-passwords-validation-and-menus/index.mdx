## The big idea

Almost every while loop is one of five shapes. Notice that every condition names a variable the body is going to change.

| Shape | Condition looks like | Used for |
|---|---|---|
| Counter | `while count > 0:` | countdowns |
| Retry | `while attempt != PASSWORD:` | logins |
| Retry with a limit | `while attempt != PASSWORD and tries < 3:` | three lives |
| Validation | `while age < 11 or age > 18:` | keeping bad input out |
| Sentinel | `while choice != "q":` | menus, quitting |

<Note title="Prime the loop">
The password loop asks for input **twice**: once before the loop, so the condition has something to test, and once inside, as the update. Delete the one inside and the loop never ends.
</Note>

## Three attempts, then locked out

`tries < 3` allows three attempts. `tries <= 3` would allow four. Trace it to be sure.
